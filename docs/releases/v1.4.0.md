# Nodalibre v1.4.0 — version de transition

Cette version marque le changement de nom de l'application vers **Nodalibre**.
Il s'agit toujours du même projet : les comptes, conversations, réglages,
clés, mémoires et workspaces existants sont conservés.

## Continuité pour les installations existantes

L'image Docker reste volontairement publiée sous son nom historique pendant
la transition :

```text
liberchat/libre-claude
```

Il ne faut donc pas remplacer le nom de l'image dans un ancien fichier
Compose. Une installation utilisant `:latest` continue à recevoir les mises à
jour normalement. Pour épingler cette version :

```bash
docker pull liberchat/libre-claude:v1.4.0
```

Les volumes `/var/www/html/data` et `/var/www/html/sandbox` ne changent pas.
Au démarrage, l'application migre les anciens noms de base et de journal quand
les permissions le permettent, avec repli compatible dans le cas contraire.

## Changements visibles

- nouveau nom **Nodalibre** et nouvelle identité visuelle indépendante ;
- suppression des références laissant penser à une affiliation avec un
  fournisseur de modèles ;
- modèles Mistral affichés sous leurs noms réels ;
- préfixe des nouveaux jetons internes `nd_sk_`, avec maintien de la lecture
  des anciens jetons ;
- documentation de la future V2 Go multi-fournisseur ;
- premier socle Go pour Mistral et ChatGPT ;
- rangement du dépôt en applications, assets, documentation et scripts.

## Mise à jour

```bash

```


```powershell

```
