# Nodalibre v1.4.1 — dernière version, fin de maintenance

**Le projet est abandonné et n'est plus maintenu. La v1.4.1 est sa dernière version.**
Aucune nouvelle version, correction de bug ou mise à jour de sécurité n'est prévue.
Il n'y aura pas de migration vers une nouvelle application ni de V2 livrée par l'équipe.

## Utiliser la dernière version avec Mistral

Cette dernière version conserve le fonctionnement avec Mistral, avec une clé API
valide et un compte autorisé à utiliser les modèles et fonctionnalités choisis.
Les usages payants nécessitent d'activer la facturation et de payer directement
Mistral. Le projet ne fournit ni crédits API ni accès gratuit garanti.

Notre volonté était de proposer une application utilisable gratuitement. Nous
sommes opposés au fait de devoir payer un fournisseur pour l'utiliser ; cette
dépendance ne correspond plus à notre objectif et motive l'arrêt du projet.

L'API Mistral reste disponible : son accès gratuit est limité et certains usages
sont payants. Consultez les [limites officielles](https://help.mistral.ai/fr/articles/698531-pourquoi-est-ce-que-j-atteins-mes-limites-d-usage-api-et-comment-les-augmenter)
et la [tarification API](https://mistral.ai/pricing/api/).

## Conservation et reprise

Les installations existantes peuvent être conservées en l'état. Sauvegardez vos
données et votre configuration, et conservez les volumes de votre instance.

Le code, les installateurs et les documents de conception restent disponibles
sous licence MIT pour permettre une reprise indépendante. Les anciens projets
de transition et de V2 sont annulés ; les documents correspondants sont conservés
uniquement à titre historique.

La publication d'une release GitHub ne prouve pas la disponibilité d'une image
Docker correspondante. Aucune future mise à jour n'est prévue.
